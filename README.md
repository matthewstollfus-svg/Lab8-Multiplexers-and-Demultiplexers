## Summary

## Lab Questions

### In plain English describe the function and use of a multiplexer.

Turns multiple inputs into one output. This can save bandwith and reduce costs.

### In plain English describe the function and use of a demultiplexer.

Takes one input and delivers it to a selected output. This can act as a data distributer.

### What other uses might these circuits have? (Think Shannon’s)

Some other uses include selecting data busses, save wiring in projects, and Shannon's creates a way to implement any boolean function through a multiplexer.
